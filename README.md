# Android Port Prototype

I have stumbled across this magnificent NES emulator made by Luke Petherbridge: https://github.com/lukexor/tetanes. What I have already seen is impressive, but I need something quick and fast for testing Rust on Android. I have also seen that it is not a simple task to port it to this platform due to storage constraints and permissions, so I have decided to create a quick and dirty prototype using Antigravity.

Yes: I'm using Antigravity in order to have a quick **prototype** (emphasis on prototype, since I do not know what the heck this AI is coding!) about what an Android NES port looks like.

However, I only know C, Python, TypeScript, Java and a bit of C++. Rust has always been in the back of my mind for a long time, maybe I will need to learn it beforehand and use this as an excuse to prove my newly acquired abilities! You know, maybe I'll clean it up and send a Pull Request if I feel like it.
